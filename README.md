# Sales & Invoicing System

Good day! This is a simple system for sales and invoicing, developed using PHP, MySQL, JavaScript, HTML, and CSS.

The system has point-of-sale (POS), inventory management, customer records, invoice generation, and admin/cashier accounts.

## Setup (IMPORTANT!)

1. Install XAMPP and start Apache and MySQL.
2. Copy only the `SalesInvoice` folder into `C:\xampp\htdocs`, so the application is at `C:\xampp\htdocs\SalesInvoice`.
3. Create a database named `salesinvoice` in phpMyAdmin (localhost/phpmyadmin).
4. Select the `salesinvoice` database, open the import tab, and import `salesinvoice.sql` from the outer `Sales Invoice System` folder.
5. Open `http://localhost/SalesInvoice/` in your browser.
